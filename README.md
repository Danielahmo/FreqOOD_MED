# Uncovering the Reliability of Frequency–Representation in Foundation Models for Medical OOD Detection

This repository accompanies our paper submitted to the **TrustFMI Workshop at ACCV 2026**. It studies how the spectral properties of distribution shifts relate to out-of-distribution (OOD) detection with DINOv2 and DINOv3 on the MIDOG and PhaKIR benchmarks from OpenMIBOOD, including a frequency-consistency regularizer applied during fine-tuning.

**The code will be released after the paper is published.**
